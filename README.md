The one git commit message a developer writes after fixing production at 3 AM.
An AI agent drafts several, scores them by the brief (joke first, then how true
it is to a 3 AM hotfix, then how much it reads like a real commit), and writes
the winner to `/output/entry.txt`. It ships:

> fix: pointed prod at the backup. the backup is a Tuesday. it is fine. I'm fine.

## Run it

```sh
python3 main.py
```
